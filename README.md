# Emmanuel — Immersive Portfolio

Versión experimental e independiente del portafolio. La landing existente sigue intacta en la carpeta padre.

El diseño busca una dirección propia —galaxia, tipografía editorial, escenas de proyectos y animación guiada por scroll— sin copiar assets, composición ni código de Active Theory.

## Ejecutar

Con la extensión Five Server activa en la raíz del workspace, abre `immersive-portfolio/index.html`. Three.js y GSAP se cargan desde CDN; las fotos, logos y páginas de proyectos reutilizan assets del sitio original mediante rutas relativas.

## Contenido

- `index.html`: secciones y contenido personal.
- `style.css`: sistema visual responsive.
- `script.js`: animaciones GSAP/ScrollTrigger y fondo WebGL de galaxia con fallback.
